# Fixed-candidate pilot (superseded for general workload claims)

32 independently seeded constructions per method, 32 queries per profile, four workloads. This retains the pre-review code and raw results. Inputs were valid distinct rows in declared domains; later API-guard findings do not invalidate these specific outcomes. All queries within a workload share one candidate set. An exact per-row membership-in-C flag is therefore an additional competent baseline; do not present these timings as evidence for arbitrary-C planning superiority. The recorded normal bands are diagnostic, not valid coverage at zero observed errors. Final implementation adds valid bounded-mean intervals.

Vendor source and prior filter_calibration.py are shared with the main research artifact. To reproduce with this archived driver, run using its original path layout or restore its code into a separate copy of the research directory; do not overwrite the live run. Main reproducible commands use the final code.
