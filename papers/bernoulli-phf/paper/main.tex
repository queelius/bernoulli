    \large An efficient implementation of the positive Bernoulli set and Bernoulli map abstract data types

\maketitle
\begin{abstract}
We derive the \gls*{gls-phf}, an immutable data structure that implements the static \emph{positive Bernoulli set}---a set with a quantifiable false positive rate and zero false negatives. Under the Bernoulli set model~\cite{bsets}, the \gls*{gls-phf} satisfies element-wise independence and conditional independence of rates. We demonstrate that the \gls*{gls-phf} is a \emph{succinct} data structure that asymptotically achieves the information-theoretic lower bound of $-\log_2 \varepsilon$~bits per element. We extend the construction to the \gls*{gls-pmf}, which implements the static \emph{Bernoulli map}~\cite{bmaps}, and demonstrate applications including fuzzy set queries for rank-ordered search. Finally, we provide a C++ implementation and compare it to the theoretical analysis.
\end{abstract}
