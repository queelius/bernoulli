\section{Approximate hash map}
\label{sec:pmf}
The approximate map generalizes the Bernoulli set to the \emph{Bernoulli map}~\cite{bmaps}: where the Bernoulli set approximates the indicator function $\mathbf{1}_A \colon U \to \{0,1\}$, the Bernoulli map approximates a general partial function $f \colon X \rightharpoonup Y$.

If the input is not in the domain of definition, the approximate map outputs a random sequence of $d$ bits. If proportion $f$ of the bit patterns represent \emph{undefined}, then the probability that an element not in the domain of definition correctly maps to undefined is $f$ and the probability that it incorrectly maps to some valid value is $1-f$.



The \emph{\gls{gls-pmf}} is a data structure given by the following definition.
\begin{definition}
The \emph{\gls{gls-pmf}} is a data structure that implements the abstract data type of the \emph{static approximate map} where both the \emph{keys} and \emph{values} are from the universe $\BitSet^*$.
A \gls{gls-pmf} that approximates a map with $m$ keys, a \emph{mean} bit length per value $\mu$, false positive rate $\fprate$, and load factor $r$ is denoted by
\begin{equation}
    \pmapf(m, \mu, \fprate, r)\,.
\end{equation}
The \emph{minimal} \gls{gls-pmf} has load factor $r=1$ and may be denoted by $\pmapf(m,\mu,\fprate)$.
\end{definition}

The minimal \gls{gls-pmf} is built exactly as the minimal \gls{gls-phf} of
\cref{alg:PHF}, with the per-slot fixed-width fingerprint replaced by the
self-delimiting value codeword: build a minimal perfect hash over the keys, then
write each value's codeword $v_j^*$ at its key's slot. \Cref{alg:shmap} states
this; on a query it is the membership test of \cref{alg:PHF_has} with the equality
check replaced by a decode of the slot codeword.

\begin{algorithm}[h]
    \caption{Construction of the minimal \gls{gls-pmf}}
    \label{alg:shmap}
    \SetKwProg{func}{function}{}{}
    \KwIn
    {
        $\Mt = \{(k_1,v_1),\ldots,(k_m,v_m)\} \subset \BitSet^* \times \BitSet^*$ is the \emph{finite map} to approximate; $\fprate$ is the false positive rate; the values are encoded by a prefix-free code with codeword $v_j^*$ for $v_j$ (\cref{def:mu}), under which a proportion $\fprate$ of bit patterns decode to defined values.
    }
    \KwOut
    {
        A minimal \gls{gls-pmf} $\Mt^* \supset \Mt$ with false positive rate $\fprate$ and false negative rate $0$.
    }
    \func{\MakeApproxMap{$\Mt$, $\fprate$}}
    {
        \tcp{Make a minimal perfect hash function for the keys.}
        $K \gets \left\{k \colon (k,v) \in \Mt\right\}$\;
        $\ph_{K} \colon \BitSet^* \mapsto \mathbb{Z}^+ \gets$ \MakeMinimalPerfectHash{$K$}\;
        $\matrx{V} \gets$ array of $m = \Card{K}$ slots\;
        \For{$j \gets 1$ \KwTo $m$}
        {
            \tcp{Store the self-delimiting value codeword at the key's slot.}
            $\matrx{V}\!\left[\ph_{K}(k_j)\right] \gets v_j^*$\;
        }
        \tcp{This pair codes the \gls{gls-pmf}.}
        \Return $\Tuple{\matrx{V}, \ph_K}$\;
    }
\end{algorithm}

To query a key $k$, decode the codeword stored at slot $\ph_K(k)$ and return its
value. A key in the domain decodes to the stored value (no false negatives in the
minimal construction); a key not in the domain reads whatever codeword occupies
its slot, which decodes to a defined value with probability $\fprate$ and to
\emph{undefined} otherwise, exactly the false positive behavior of
\cref{sec:pmf_rates}. The slot width is set by the codeword: a fixed-width
$M = \lceil -\log_2\fprate \rceil$ codeword recovers the \gls{gls-phf} fingerprint
of \cref{alg:PHF} (the $\mu = 0$ case of \cref{rem:pmf_specializes}), and a
variable-width prefix-free code carries the value content at mean cost $\mu$
(\cref{def:mu}). Relaxing the minimal perfect hash to a $k$-perfect hash
introduces a false negative rate $\omega$ by the collision mechanism of
\cref{thm:k_omega}, the value being the content overwritten on a collision,
exactly as the fingerprint is in \cref{alg:k_PHF}.


\subsection{The two rates of the map}
\label{sec:pmf_rates}
Before bounding the space, we record the error model the \gls{gls-pmf} realizes, which is the static \emph{Bernoulli map}~\cite{bmaps} specialized to the perfect-hash realization. A query on a key $k$ proceeds exactly as in the set case (\cref{alg:shmap}): the perfect hash locates the slot $\ph_K(k)$ and the stored codeword is decoded.
\begin{enumerate}
    \item For a key in the domain of definition, the decode returns the stored value, so the false negative rate is $\fnrate = 0$ in the minimal construction. (Relaxing the perfect hash to a $k$-perfect hash introduces a false negative rate $\omega$ by exactly the collision mechanism of \cref{thm:k_omega}; the value, like the fingerprint, is the content overwritten on a collision.)
    \item For a key not in the domain of definition, the slot's codeword decodes to a spurious value rather than to \emph{undefined} with probability $\fprate$. As in the entropy-map construction~\cite{bmaps,emaps}, if a proportion $\fprate$ of bit patterns decode to defined values then an out-of-domain key is incorrectly reported as defined with probability $\fprate$. The \gls{gls-pmf} thus implements the positive Bernoulli map with false positive rate $\fprate$.
\end{enumerate}

We make precise the per-element value cost that enters the bounds.
\begin{definition}[Mean value cost]
\label{def:mu}
Let the values $v_1,\ldots,v_m$ be encoded by a prefix-free (self-delimiting) code, with $v_j^*$ the codeword for $v_j$ and $\BL(v_j^*)$ its bit length. The \emph{mean value cost} is the per-element expected codeword length,
\begin{equation}
\label{eq:mu_def}
    \mu \coloneqq \frac{1}{m}\sum_{j=1}^{m} \BL(v_j^*)\,.
\end{equation}
When the values are drawn from a distribution $p_{\RV{Y}}$ and the code is optimal, $\mu$ attains the value entropy $H(\RV{Y}) = -\sum_y p_{\RV{Y}}(y)\log_2 p_{\RV{Y}}(y)$ by Shannon's source coding theorem~\cite{bmaps}.
\end{definition}

\subsection{Lower-bound on space complexity}
\label{sec:pmf_lower_bound}
The \gls{gls-pmf} is the map analogue of the \gls{gls-phf}: the bit matrix $\matrx{V}$ stores, at each perfect-hash slot, a value codeword in place of a fixed-width fingerprint. Its space bound is obtained by specializing the Bernoulli-map space bound to this realization, exactly as \cref{thm:mPHF_size} specialized the set bound.

\begin{theorem}[Space lower bound for the \gls{gls-pmf}]
\label{thm:pmf_lower_bound}
The \emph{expected} bit length of the \gls{gls-pmf} with $m$ keys, mean value cost $\mu$ (\cref{def:mu}), false positive rate $\fprate$, and load factor $r$ has a lower bound of
\begin{equation}
\label{eq:pmf_lower_bound}
    \log_2 e
    \;-\; \left(\frac{1}{r} - 1\right)\log_2\!\left(\frac{1}{1-r}\right)
    \;+\; \frac{1}{r}\bigl(-\log_2 \fprate + \mu\bigr)
    \quad \si{bits \per element}\,.
\end{equation}
In the minimal case $r = 1$ this reduces to
\begin{equation}
\label{eq:pmf_lower_bound_minimal}
    \log_2 e \;-\; \log_2 \fprate \;+\; \mu \quad \si{bits \per element}\,.
\end{equation}
\end{theorem}
\begin{proof}
The encoding is the pair $\Tuple{\matrx{V}, \ph_K}$ of the value matrix and the perfect hash, so its expected length is the sum of the perfect-hash cost and the content cost, the same decomposition as in the proof of \cref{thm:mPHF_size}.

The perfect-hash cost is unchanged from \cref{thm:mPHF_size}: a load-factor-$r$ perfect hash over $m$ keys costs, in expectation, $\log_2 e - \left(\tfrac{1}{r}-1\right)\log_2\!\left(\tfrac{1}{1-r}\right)$ bits per element, with the floor $\log_2 e \approx \num{1.4427}$ at $r=1$~\cite{mehlhorn1982}, since the slot-assignment problem is identical for the set and the map.

The content cost is the map specialization. For the value content, \cref{thm:approx_l_b}'s set quantity $-\log_2\fprate$ (the per-element fingerprint width that realizes the false positive rate) is replaced by the Bernoulli-map per-element bound $-\log_2 \fprate + \mu$ of~\cite{bmaps,emaps}: a slot codeword must simultaneously realize the false positive rate $\fprate$ and carry the value, and the information-theoretic minimum to do both, per defined element, is $-\log_2 \fprate + \mu$ bits (the $-\log_2\fprate$ term is the rate-distortion cost of the false positive rate on out-of-domain keys and the $\mu$ term is the value content of \cref{def:mu}). The matrix $\matrx{V}$ has $N = m/r$ slots, so the total content is $\tfrac{m}{r}\bigl(-\log_2\fprate + \mu\bigr)$ bits, that is $\tfrac{1}{r}\bigl(-\log_2\fprate + \mu\bigr)$ per element.

Summing the two contributions gives \cref{eq:pmf_lower_bound}. Setting $r = 1$, the correction term $\left(\tfrac{1}{r}-1\right)\log_2\!\left(\tfrac{1}{1-r}\right)$ vanishes (its limit as $r\to 1$ is $0$) and the content term is $-\log_2\fprate + \mu$, yielding \cref{eq:pmf_lower_bound_minimal}.
\end{proof}

\begin{remark}
\label{rem:pmf_specializes}
Setting $\mu = 0$ (a one-element codomain, so the map carries no value, only membership) recovers \cref{thm:mPHF_size} for the \gls{gls-phf}: the \gls{gls-pmf} bound is the set bound plus the per-element value content $\mu/r$. The minimal bound \cref{eq:pmf_lower_bound_minimal} is the entropy-map bound $-\log_2\fprate + \mu$ of~\cite{bmaps} plus the $\log_2 e$ minimal-perfect-hash floor, the same $\log_2 e$ overhead the minimal \gls{gls-phf} pays over the set bound of \cref{thm:approx_l_b}.
\end{remark}

\subsection{Upper-bound on entropy}
\label{sec:pmf_entropy}
We now show the \gls{gls-pmf} construction (\cref{alg:shmap} in the minimal case, and its load-factor-$r$ generalization with a $k$-perfect hash) attains the lower bound of \cref{thm:pmf_lower_bound} in expectation: its code carries no more information than the bound permits, so it is a maximum-entropy coder for the Bernoulli map, the map analogue of \cref{thm:max_entropy_coder}.

\begin{theorem}[Entropy upper bound for the \gls{gls-pmf} code]
\label{thm:pmf_entropy}
Conditioned on the key cardinality $m$, the false positive rate $\fprate$, and the value distribution, the random bit string that codes the \gls{gls-pmf} (\cref{alg:shmap} and its load-factor-$r$ generalization) has expected length, equivalently entropy, at most
\begin{equation}
\label{eq:pmf_entropy}
    \Expect{\BL(\Mt^*)}
    = m\!\left(\log_2 e - \left(\tfrac{1}{r}-1\right)\log_2\!\left(\tfrac{1}{1-r}\right) + \tfrac{1}{r}\bigl(-\log_2\fprate + \mu\bigr)\right) \si{bits}\,,
\end{equation}
with no further structure imposed beyond the Bernoulli-map axioms, so the bound of \cref{thm:pmf_lower_bound} is attained.
\end{theorem}
\begin{proof}
The code is the pair $\Tuple{\matrx{V}, \ph_K}$ of the value matrix and the perfect hash, where the load-factor-$r$ perfect hash is itself coded by the seed of its construction (\cref{thm:mPHF_size}). By the argument of \cref{thm:max_entropy_coder}, the seed bits are uniform (the seed is the index of the first acceptable draw among i.i.d.\ uniform candidates), so the perfect-hash component contributes its expected cost $m\bigl(\log_2 e - (\tfrac{1}{r}-1)\log_2(\tfrac{1}{1-r})\bigr)$ bits and no more, this being the same maximum-entropy seed encoding as in the set case.

For the content, each slot of $\matrx{V}$ holds a self-delimiting codeword whose decoding under the prefix-free code realizes the value with mean length $\mu$ (\cref{def:mu}) and realizes the false positive rate $\fprate$ on out-of-domain keys: by the optimality of the entropy-map encoding~\cite{bmaps,emaps}, the expected content per slot is $-\log_2\fprate + \mu$ bits and, conditioned on $m$, $\fprate$, and the value distribution, every coded bit beyond what these constraints fix is an independent fair coin. Hence the content carries maximum conditional entropy at this expected length, and over the $N = m/r$ slots contributes $\tfrac{m}{r}\bigl(-\log_2\fprate+\mu\bigr)$ bits. Summing the two components gives \cref{eq:pmf_entropy}, which equals $m$ times the per-element lower bound of \cref{eq:pmf_lower_bound}; the lower bound is therefore attained in expectation, and since no structure beyond the axioms is imposed, the code is a maximum-entropy coder for the static Bernoulli map.
\end{proof}
