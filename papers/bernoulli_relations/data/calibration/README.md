# Stored-filter calibration artifact

These results were generated by `../../code/filter_calibration.py` with its
defaults: seed 20261013, 160 accepted builds per method, 128 disjoint bundles per
truth profile, a 12-source binary-witness cycle, and query-FP target 0.05.
The script requires only Python 3.11 or later.

From the relations paper root:

```bash
python3 code/filter_calibration.py
```

From the workspace root with the existing development environment:

```bash
bernoulli-py/.venv/bin/python papers/bernoulli_relations/code/filter_calibration.py
bernoulli-py/.venv/bin/python -m pytest papers/bernoulli_relations/code/test_filter_calibration.py --cov=filter_calibration --cov-branch --cov-report=term-missing -q
```

The script overwrites the four result files in this directory; choose `--output`
to save another run. Counts, accepted salts, and payload hashes reproduce for the
recorded configuration and environment. Timing values vary between runs.

- `results.json`: configuration, runtime environment, source hash, model and
  uncertainty qualifications, and summarized results.
- `summary.csv`: one row per method and truth profile.
- `builds.csv`: one row per accepted construction, including salt, insertion
  count, dimensions, occupancy, query envelope, attempts, payload hash/bytes,
  time, and inserted-key false-negative count.
- `queries.csv`: per-construction query counts, conditional ideal predictions,
  timing, and deterministic repeat/reversal checks.

The canonical representations insert 2,816 symmetry-orbit representatives;
ordered OR repair inserts 5,632 directed keys. All measured queries use serialized
and reloaded partitioned Bloom bytes, not simulated query coins or an exact-set
membership oracle. Repeated lookup is deterministic. Portable payload includes
the actual bit array and a 40-byte metadata/salt header, excluding Python object
overhead and the common exact witness/input tables.

Initial sizing is followed by insertion-only salt rejection until the product
of occupied partition fractions is at most the source target. Under ideal
independent random functions this certifies a conditional query bound: exponent
eight for canonical cycle sources, sixteen for ordered keys with OR repair.
Stopping depends only on inserted-key hashes, so it does not select on absent-key
answers. BLAKE2b domain separation is the concrete mechanism and is **not a proof
of the ideal independence assumption**.

At boundary truth, the observed false-positive rates are 0.32915 for naïve
canonical sizing, 0.04907 for calibrated canonical sizing, and 0.05103 for
calibrated ordered OR repair. Approximate 95% intervals use the 160 independent
construction means as units; they do not assume independent same-build queries.
The two calibrated intervals include the target and their conditional-model
predictions. The ordered point estimate slightly exceeds 0.05: empirical
agreement is not an exact concrete-hash guarantee. Canonical calibrated storage
uses 3,752 bytes versus 8,482 for ordered OR repair, a 55.8% reduction in this
probe. All inserted/true-query false-negative and repeat/reversal mismatch
counts are zero.

That 55.8% comparison combines canonicalization with the extra OR-repair budget.
Holding canonical storage fixed isolates a much smaller independence benefit:
the source budget `1-0.95^(1/8)` sizes to 3,752 bytes, while the conservative
union-bound budget `0.05/8` sizes to 3,768 bytes (16 bytes, or 0.425%). These
dimensions are recorded under `canonical_budget_sizing` in `results.json`;
this is a sizing calculation, not a fourth measured filter method. Reproduce it
from the workspace root without rebuilding filters:

```bash
bernoulli-py/.venv/bin/python -m pytest papers/bernoulli_relations/code/test_filter_calibration.py -q -s -k dependence_budget
```

The construction's floating-point acceptance calculation is not generally
outward-certified. A separate exact `Fraction` audit reconstructs `p(C)` from
the saved integer occupancies and checks the query bound against exactly `1/20`.
All 320 calibrated accepted builds pass; the smallest slack is approximately
`4.66555e-6`. The audit requires no filter rebuild and can be reproduced with:

```bash
bernoulli-py/.venv/bin/python -m pytest papers/bernoulli_relations/code/test_filter_calibration.py -q -s -k exact_recorded
```

This last command assumes the workspace root. All 480 accepted structures also
pass an exact check against their original binary floating source thresholds,
so adding an exact final acceptance check would retain every recorded structure.
The current comparator uses stable `expm1/log1p` for ordered OR and accumulates
cycle success mass directly, preserving tiny positive probabilities. Regression
tests compare against exact rational values down to source rate `2^-120`.
A full default rerun refreshed all generated data after that correction. Its
payload hashes, attempt counts, and observed query outcomes match the preceding
run; the recorded source hash matches the corrected code.
