\begin{abstract}
We define the \emph{Bernoulli map}, a probabilistic function $\APFun{f}[\fprate][\fnrate] \colon \Set{X} \to \Maybe{\Set{Y}}$ that approximates an objective map $\Fun{f}$ with per-element errors modeled as independent Bernoulli trials. This generalizes the Bernoulli set model from indicator functions $\Set{X} \to \BitSet$ to arbitrary codomains. We introduce \emph{model order} as the minimum number of domain partitions yielding i.i.d.\ error indicators within each block, and derive the composition theorem: the false negative rate of $\APFun{g} \circ \APFun{f}$ satisfies $\fnrate_{g \circ f} = 1 - (1-\fnrate_1)(1-\fnrate_2)$, while the false positive rate depends on the overlap between false-positive values and the second map's domain. We show that the model specializes to Bernoulli sets, binary symmetric and asymmetric channels, and approximate constants. Finally, we present the \emph{entropy map}, a space-optimal theoretical construction, and the \emph{singular hash map}, a concrete algorithm achieving the information-theoretic lower bound of $-\log_2 \fprate + \mu$ bits per element.
\end{abstract}
