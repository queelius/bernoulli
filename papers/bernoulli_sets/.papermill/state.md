## Thesis

The Bernoulli set model is a two-axiom probabilistic framework for random approximate sets: element-wise independence and conditional independence of block error rates suffice to derive binomial error-count distributions, asymptotic limits, confidence intervals, and the higher-order composition theorem via channel transition matrices. Formulated as an abstract data type, any implementation satisfying the axioms (Bloom filters, perfect hash filters, etc.) inherits the full theory automatically.
