\section{Channel Capacity in the BSC}
\label{sec:bsc-capacity}

The binary symmetric channel of \Cref{sec:bsc} reproduces its Boolean input
with probability $1 - \fprate$ and flips it with probability $\fprate$
regardless of the value sent, the channel matrix being $Q =
\left(\begin{smallmatrix} 1 - \fprate & \fprate \\ \fprate & 1 - \fprate
\end{smallmatrix}\right)$ (\Cref{def:bsc}). Its capacity is the quantitative
information-theoretic summary chapter~2 left implicit.

\begin{proposition}[BSC capacity]
\label{prop:bsc-capacity}
The capacity of the BSC with crossover $\fprate \in (0, 1)$ is
\begin{equation}
\label{eq:bsc-capacity}
  C \;=\; 1 - H(\fprate)
  \;=\; 1 + \fprate \log_2 \fprate + (1 - \fprate)\log_2(1 - \fprate)
  \quad \text{bits per use,}
\end{equation}
attained by the uniform input $\Prob{X = \top} = \Prob{X = \bot} = 1/2$.
\end{proposition}

\begin{proof}
Compute $I(X; Y) = H(Y) - H(Y \mid X)$ (the second form of
\eqref{eq:mutual-info}), with input distribution $\Prob{X = \top} = q$. Given
$X = \top$, the output is $\mathrm{Bernoulli}(\fprate)$ with entropy
$H(\fprate)$ by \eqref{eq:binary-entropy}; the same holds for $X = \bot$ since
the rows of $Q$ are permutations, so $H(Y \mid X) = q H(\fprate) + (1 - q)
H(\fprate) = H(\fprate)$, independent of $q$. The output marginal is
$\Prob{Y = \top} = q(1 - \fprate) + (1 - q)\fprate = \fprate + q(1 - 2\fprate)$,
which equals $1/2$ at $q = 1/2$, where $H(Y) = H(1/2) = 1$ is maximal; for any
other $q$ strict concavity gives $H(Y) < 1$. Hence $I(X; Y) = H(\fprate +
q(1 - 2\fprate)) - H(\fprate)$ is maximized at $q = 1/2$, giving $C = 1 -
H(\fprate)$.
\end{proof}

Once $\fprate$ is fixed the channel admits at most $C$ bits per use, and by
Shannon's noisy-channel coding theorem this ceiling is asymptotically
achievable: for any rate $R < C$ there are long block codes with decoding
error below any $\varepsilon$. The closed form has a sharp shape. At $\fprate
= 0$ the channel is noiseless, $H(0) = 0$ and $C = 1$. At $\fprate = 1/2$ the
output is a fair coin independent of the input, $H(1/2) = 1$ and $C = 0$. At
$\fprate = 1$ the channel always flips, which a receiver undoes by relabeling
$\top \leftrightarrow \bot$, so $H(1) = 0$ and $C = 1$ again; $C(\fprate)$ is
symmetric about $\fprate = 1/2$. The curve is steep near $0$ (the first
crossover noise costs little: $C(0.01) \approx 0.919$) and shallow near $1/2$
(the last noise costs almost everything: $C(0.1) \approx 0.531$, $C(0.4)
\approx 0.029$).

The same source-coding principle drives the rest of the chapter through a
different question: how many bits represent an approximate set at target
$\fprate$? Any prefix-free encoding of a source emitting $n$ symbols of
entropy $H$ each needs at least $nH$ bits on average, and
\Cref{sec:entropy-floor} applies this to the bit string an approximate set
stores, with the constrained per-element entropy giving a floor of $-\log_2
\fprate$ bits per element for any FNR-zero representation. Capacity and the
floor are two faces of one principle, with $H$ holding throughout.
