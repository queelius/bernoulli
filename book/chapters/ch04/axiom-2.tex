\section{Axiom 2: Conditional Independence of Block Error Rates}
\label{sec:axiom-2}

Axiom~1 governs error across distinct elements; Axiom~2 governs the random
per-block rates. The model partitions the input domain into blocks $B_1,
\ldots, B_n$ sharing a rate each (\Cref{sec:model-order}); for the Boolean
domain the blocks are $B_1 = \{\top\}$, carrying $\fnrate$, and $B_2 =
\{\bot\}$, carrying $\fprate$.

\begin{axiom}[Conditional independence of block error rates]
\label{ax:block-rates-indep}
The random per-block rates $\alpha_1, \ldots, \alpha_n$, conditional on the
objective set $A$, are mutually independent:
$f(\alpha_1, \ldots, \alpha_n \mid A) = \prod_i f(\alpha_i \mid A)$.
\end{axiom}

Knowing the error rate on one block tells you nothing about another's. In the
order-2 Boolean case this is the single statement that $\fprate$ and $\fnrate$
are conditionally independent given $A$, the instance that arises throughout the
book. The rates are random in the sense that they may vary across realizations
of the data structure (a Bloom filter's false-positive rate depends on which
elements were inserted); Axiom~2 constrains how those rates relate across
blocks, not across elements within a block, which is Axiom~1's identically-
distributed clause.

\begin{proposition}[Stable channel matrices]
\label{prop:stable-Q}
Under \Cref{ax:block-rates-indep} (with \Cref{ax:element-indep}), the channel
row for block $B_i$ is the same at every query of an element of $B_i$,
independent of the order or history of prior queries.
\end{proposition}

\begin{proof}
The output distribution for an element of $B_i$ depends only on the realized
rate $\alpha_i$, which Axiom~2 makes independent of the other blocks' rates and
which is drawn once for the structure; by Axiom~1 the per-element error events
are conditionally independent given $\alpha_i$. The row of $Q$ for $B_i$ is
therefore a fixed function of $\alpha_i$ at every query, with no dependence on
prior outcomes, so it is stable across the sequence.
\end{proof}

This is the precise sense of ``one channel matrix $Q$ per block'': the entry
$Q_{ij}$ does not drift or warm up, and a single $Q$ describes an entire query
sequence. A channel that violates this is a Markov-correlated one, where the
rate after an error rises from a base $\fprate_0$ to an elevated $\fprate_1$.
With $\fprate_0 = 0.05$ and $\fprate_1 = 0.30$, two consecutive negatives are
both reported $\top$ with probability $0.05 \times 0.30 = 0.015$, six times the
$\fprate_0^2 = 0.0025$ that a stable rate predicts. Error clustering of this
kind is invisible to the factored model and is exactly what Axiom~2 forbids; a
Markov channel must be handled by augmenting the state, after which the standard
machinery applies to the augmented model.

Stability is what makes the Kronecker factorization possible
(\Cref{sec:kronecker}): the $m$-query joint matrix is a product of copies of one
stable $Q$. The payoff is parametric. A general order-$n$ channel on $m$ joint
queries needs $n(2^m - 1)$ parameters in the per-source-block convention; under
the two axioms the Kronecker structure forces $nm$, with no cross-query terms.
For the order-2 Boolean channel at $m = 50$ that is $2m = 100$ parameters rather
than $2(2^{50} - 1) \approx 2.25 \times 10^{15}$. (One subtlety, taken up in
\Cref{sec:kronecker}: this count is exact for the rate-conditional matrix
always, and for the unconditional matrix when rates are deterministic or no
block is queried twice, \Cref{cor:kronecker-unconditional}; same-block queries
on genuinely random rates incur a Jensen gap.)
