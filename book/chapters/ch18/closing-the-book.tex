\section{Closing the Book}
\label{sec:closing-the-book}

The book built one framework in five parts and eighteen chapters, each
part lifting the preceding part's algebra to a larger domain and each
chapter filling in one component of the lift. This section traces the arc.

\subsection*{The atom and its lifts}

Part~I opened with the noisy bit (\Cref{ch:noisy-bit}), a Boolean value
crossing a binary channel that flips it with known probability, and named
the two atomic parameters, the false-positive rate $\fprate$ and the
false-negative rate $\fnrate$, jointly inhabiting the Bernoulli square.
\Cref{ch:axioms-kronecker} formalized the atom: $\Bernoulli{\BoolType}$
(\Cref{def:bernoulli-bool}) collects all $(\fprate, \fnrate)$ channels, the
two axioms (\Cref{ax:element-indep}, \Cref{ax:block-rates-indep}) prescribe
how atoms combine, and the Kronecker theorem (\Cref{thm:kronecker}) gives
the composition law as a matrix product. Part~I closed with the whole
machinery distilled into one $2 \times 2$ matrix per atom and a Kronecker
product for composition.

Part~II lifted the atom to a set of bits, one per element of a universe.
\Cref{ch:approximate-sets} framed the random approximate set as a function
from a plaintext set to a sequence of atoms; \Cref{ch:set-composition}
worked out the composition theorem for union, intersection, complement,
and difference, with the perfect-filter line marking the structures
(Bloom filters chief among them) on the $\fnrate = 0$ axis;
\Cref{ch:classification-measures} lifted the atomic rates to the derived
measures (precision, recall, PPV, NPV, $\Fone$, Youden's $J$); and
\Cref{ch:information-bounds} priced approximate membership at the entropy
floor $-\log_2 \fprate$ bits per element. Part~II closed with the algebra
of approximate sets fully priced: construction bounded by Shannon,
composition by Kronecker, classification by the chapter 7 posterior.

Part~III lifted from sets to functions. \Cref{ch:approximate-functions}
took the binary channel to its $n$-ary generalization, the random
approximate map; \Cref{ch:sketches-estimators} treated the streaming
sketches that compress the map into bounded memory;
\Cref{ch:randomized-algorithms} extended the framework to randomized
algorithms; \Cref{ch:approximate-relations} took the relational lift; and
\Cref{ch:algebra-types} unified them, every Bernoulli-lifted structure an
instance of $\Bernoulli{T}$ for some type $T$, the compositions inheriting
from the algebra of types.

\subsection*{The optimum, the boundary, the applications}

Part~IV asked whether the space-accuracy lower bound is achievable.
\Cref{ch:optimal-bernoulli-sets} answered yes for the FNR-zero set: the
Bernoulli hash function reaches the chapter 8 entropy floor within a
vanishing additive overhead, explicitly. \Cref{ch:perfect-hash-filters}
gave the FPR-zero counterpart for ranked retrieval, where the error budget
is the false-negative side. Part~IV exhibited the algebra's bounds as
operationally achievable, not merely necessary.

Part~V drew the boundary and turned the algebra to use.
\Cref{ch:not-bernoulli} catalogued where the framework fails, when the
rates are not iid, the channel non-stationary, or the inputs adversarial,
and what replaces the broken machinery. \Cref{ch:cipher-maps-trapdoor}
took the algebra to the cryptographic setting, cipher maps generalizing
the atoms to the trapdoor-computing paradigm with the chapter 7 PPV
re-read as the confidentiality measure. \Cref{ch:encrypted-search}, the
present chapter, instantiated cipher maps for a working application,
encrypted search with Bloom-filter indexing, where the rate-prevalence
triangle prices the trade-off between recovery and leakage.

\subsection*{What comes next}

The framework is not exhausted by the eighteen chapters. Three threads
point past its current scope: approximate query languages that lift the
chapter 12 relational algebra to a declarative interface with
framework-priced execution costs; federated computation, where the
cipher-map machinery generalizes to multiple parties each holding partial
trapdoor keys; and the relation to differential privacy, which uses a
structurally similar noise-budget abstraction, with the noise explicitly
controlled rather than emergent, and which the framework should ultimately
subsume as a constrained sibling. Each is a working extension, not a
planned chapter; the book closes with the framework in a state that admits
the extensions but does not require them.
