\section{Capacity for n-ary Channels}
\label{sec:n-ary-capacity}

The BSC capacity $C = 1 - H(\fprate)$ of \Cref{prop:bsc-capacity} is the
$K = L = 2$ case of a definition that lifts to any $K \times L$ channel. The
lift is mostly definitional; what changes is that the optimization no longer has
a single closed form except for a symmetric sub-family.

\subsection*{The general case}

For an n-ary channel (\Cref{def:n-ary-channel}), an input distribution $P_X$ on
the $K$ blocks induces $P_Y(j) = \sum_{i} P_X(B_i) Q_{ij}$, and the capacity
\eqref{eq:capacity-def}\index{channel capacity} is
\begin{equation}
\label{eq:n-ary-capacity-def}
  C \;=\; \max_{P_X}\, \bigl[ H(Y) - H(Y \mid X) \bigr],
  \qquad H(Y \mid X) = \sum_{i=1}^{K} P_X(B_i)\, H(Q_{i\,\cdot}),
\end{equation}
the same object as the BSC's, now over the $(K-1)$-simplex rather than the
interval $[0,1]$. The mutual information\index{mutual information} is concave in $P_X$, so the maximum
exists, but the maximizer satisfies implicit stationarity conditions with no
closed form in general. The \emph{Blahut--Arimoto} algorithm, an alternating
fixed-point iteration over $P_X$ and the posterior $\Prob{X \mid Y}$, converges
geometrically to the capacity-achieving distribution (\textcite[Ch.~10]{cover-thomas}),
making the general n-ary capacity computable to any precision.

\begin{remark}[The output-entropy ceiling]
\label{rem:capacity-bound}
Every n-ary channel obeys $C \le \log_2 L$: since $H(Y \mid X) \ge 0$,
$C \le \max_{P_X} H(Y) \le \log_2 L$, the maximum entropy of an $L$-symbol
alphabet. Equality requires both $H(Y \mid X) = 0$ (the channel is a noise-free
function of the input) and an input distribution making $P_Y$ uniform, that is,
a deterministic surjection from input blocks onto the $L$ outputs. This is the
n-ary ceiling that $\log_2 2 = 1$ bit was for the BSC.
\end{remark}

\subsection*{Symmetric channels}

The BSC's closed form rested on two facts: its rows are permutations of one
another (so $H(Y \mid X)$ is input-independent) and its columns are too (so
uniform input gives uniform output). Lifting both gives a sub-family with a
closed-form capacity.

Call a channel \emph{weakly symmetric} if every row of $Q$ is a permutation of a
common multiset $\mathbf{r} = (r_1, \ldots, r_L)$ \emph{and} every column has the
same sum. The first condition makes $H(Y \mid X) = H(\mathbf{r})$
input-independent; the second makes the uniform input $P_X(B_i) = 1/K$ produce
the uniform output $P_Y(j) = 1/L$, attaining $H(Y) = \log_2 L$. (Rows being
permutations of one another does \emph{not} alone uniformize the output: the
column sums must match.) Hence
\begin{equation}
\label{eq:symmetric-capacity}
  C \;=\; \log_2 L \;-\; H(\mathbf{r}),
\end{equation}
the n-ary analogue of $C = 1 - H(\fprate)$: the ceiling $\log_2 L$ less the
irreducible per-use row uncertainty $H(\mathbf{r})$.

A \emph{strongly symmetric} channel has, in addition, columns that are
permutations of one another. The clean parametrization spreads a single error
probability $p_e$ uniformly over the $L - 1$ wrong outputs,
\[
  Q_{ij} =
  \begin{cases}
    1 - p_e & j = i, \\
    p_e/(L - 1) & j \neq i,
  \end{cases}
\]
a square $K = L$ matrix with the BSC as its $L = 2$, $p_e = \fprate$ instance.

\begin{proposition}[Strongly symmetric n-ary capacity]
\label{prop:n-ary-capacity}
A strongly symmetric channel with output size $L$ and per-input error $p_e \in
[0, 1)$ has capacity
\begin{equation}
\label{eq:strongly-symmetric-capacity}
  C \;=\; \log_2 L \;-\; H\!\left(1 - p_e,\; \tfrac{p_e}{L-1},\; \ldots,\;
          \tfrac{p_e}{L-1}\right)
  \quad \text{bits per use,}
\end{equation}
attained at the uniform input.
\end{proposition}

At $L = 2$, $p_e = \fprate$, the row $(1 - \fprate, \fprate)$ has entropy
$H(\fprate)$ and $C = 1 - H(\fprate)$, recovering \eqref{eq:bsc-capacity}. The
endpoints carry over: $p_e = 0$ gives $C = \log_2 L$ (noiseless $L$-ary
channel), and $p_e = (L-1)/L$ gives the uniform row and $C = 0$.

\subsection*{Worked example}

Take $L = 4$, $p_e = 0.1$, so each off-diagonal entry is $0.1/3 \approx 0.0333$
and the channel is strongly symmetric. The ceiling is $\log_2 4 = 2$ bits. The
row entropy is
\[
  H(\mathbf{r}) = -0.9 \log_2 0.9 - 3 \cdot \tfrac{0.1}{3} \log_2 \tfrac{0.1}{3}
  \approx 0.137 + 0.490 = 0.627 \text{ bits,}
\]
so $C = 2 - 0.627 \approx 1.373$ bits per use, well below the noiseless ceiling
of $2$ and well above the BSC's $0.531$ at the same per-symbol error $0.1$. As
$L$ grows at fixed $p_e$ the error mass spreads more thinly over the wrong
outputs. In absolute terms the gap $H(\mathbf{r}) = H(p_e) + p_e
\log_2(L-1)$ (with $H(p_e)$ the binary entropy) grows with $L$, but only logarithmically, so the relative capacity
$C/\log_2 L$ tends to $1 - p_e$. \Cref{sec:bridge-to-sketches}
previews how concrete sketches can each be read as an n-ary channel with its
own $Q$ and its own symmetry.
