\section{\texorpdfstring{$\Bernoulli{T}$}{Bernoulli T} for Composite \texorpdfstring{$T$}{T}}
\label{sec:bernoulli-of-composite}

This section gives the lift $\Bernoulli{-}$ on each constructor. Three of the
four factor cleanly; the sum is the exception.

\subsection*{Product types: the Kronecker isomorphism}

A noisy pair is a pair of noisy values. If $\tilde t$ has channel $Q_T$ and
$\tilde u$ has channel $Q_U$, with independent noise, the joint channel at each
$(t, u)$ is the product of the marginals, so the joint matrix is the Kronecker
product $Q_T \otimes Q_U$, the chapter-4 and chapter-9 factorization
(\Cref{thm:kronecker}, \Cref{thm:n-ary-kronecker}) read at the type level.

\begin{theorem}[Product-type isomorphism]
\label{thm:bernoulli-product}
For types $T, U$ with independent noise channels, $\Bernoulli{T \times U} \cong
\Bernoulli{T} \otimes \Bernoulli{U}$, the Kronecker product of the component
channels: a $K_T K_U \times L_T L_U$ matrix with $(Q_T \otimes Q_U)_{(j_T, j_U),
(\ell_T, \ell_U)} = (Q_T)_{j_T, \ell_T}(Q_U)_{j_U, \ell_U}$.
\end{theorem}

Axiom~1 factors the joint into a product across components and Axiom~2 keeps each
row stable, so the proof is the chapter-9 calculation with the two factors now of
different dimensions. The parameter count is additive: without independence the
joint would need $K_T K_U(L_T L_U - 1)$ parameters, but under it only $K_T(L_T -
1) + K_U(L_U - 1)$, the parameters of $Q_T$ plus those of $Q_U$. Products are the
well-behaved case, where approximation distributes and parameters grow
additively.

\subsection*{Sum types: the tag error breaks the factorization}

A sum $T + U$ tags each value $\mathrm{Left}(t)$ or $\mathrm{Right}(u)$. An
approximate sum value errs in two ways: a \emph{tag error} flips the tag with
probability $\delta$, and a \emph{payload error} corrupts the value within the
correct component at rate $\fprate_T$ or $\fprate_U$. For a latent
$\mathrm{Left}(t)$,
\[
  \Prob{\widetilde{\mathrm{Left}(t)}} = (1 - \delta)(1 - \fprate_T),
  \quad
  \Prob{\mathrm{Left}(t'\!\neq t)} = (1 - \delta)\tfrac{\fprate_T}{|T| - 1},
  \quad
  \Prob{\mathrm{Right}(\cdot)} = \delta,
\]
the last spread over the wrong component.

\begin{proposition}[Sum types do not factor]
\label{prop:sum-nonfactor}
$\Bernoulli{T + U} \not\cong \Bernoulli{T} \oplus \Bernoulli{U}$ in general: the
confusion matrix of an approximate sum does not factor as a direct sum of
per-component channels.
\end{proposition}

The reason is structural and is the heart of the product-versus-sum distinction.
In a product, both components are always active and independent, so the channel
tensors. In a sum, the tag error \emph{couples} the components: when the tag is
correct only one component's payload channel applies, and when it is wrong the
value is drawn from the \emph{other} component entirely. The block-diagonal form
$\Bernoulli{T} \oplus \Bernoulli{U}$ (one payload channel per summand, zero
off-diagonal) is only the $\delta = 0$ degenerate case, a sum with an exact tag;
any tag noise puts mass in the off-diagonal blocks and no factorization
recovers it. This is Core Principle~2: products preserve parametric parsimony, sums
break it.

The break is not a peripheral failure. The optional type $\mathrm{Maybe}(T) = T +
\Unit$ adds a ``nothing'' case, and its tag error \emph{is} approximate set
membership: a tag flip on $\mathrm{Just}(t)$ produces $\mathrm{Nothing}$, a false
negative, and a flip on $\mathrm{Nothing}$ produces some $\mathrm{Just}(t)$, a
false positive, with $\delta = \fprate$ for negatives and $\delta = \fnrate$ for
positives. The sum's tag error is exactly the atomic membership error the whole
framework rests on, which is why the sum constructor cannot be made to factor:
factoring it away would factor away the framework's irreducible rate.

\subsection*{List and function types}

A list of known length $n$ is the product $T^n$, so $\Bernoulli{T^n} \cong
\Bernoulli{T}^{\otimes n}$, the Kronecker power of the per-position channel, with
parameter count $K_T(L_T - 1)$ independent of $n$. A variable-length list,
however, is a \emph{sum} over lengths, $L T \cong \sum_{n \ge 0} T^n$, so a noisy
length is a sum-type tag error over the length index: $\Bernoulli{L T}$ is a
mixture over the noisy length (a $\Bernoulli{\mathbb{N}}$), each component a
per-position Kronecker product, and it does not reduce to a single clean product.
A HyperLogLog cardinality estimate is exactly this noisy length, composing with
per-element noise by the mixture rule, not by a simple per-element product.

A noisily approximated function $f : T \to U$ produces one $\Bernoulli{U}$ per
input, so $\Bernoulli{T \to U} \cong T \to \Bernoulli{U} \cong \prod_{t \in T}
\Bernoulli{U}$, the chapter-9 framework: the channel is a function from input
blocks to output distributions. This factors over inputs as a Kronecker product
of $|T|$ per-input channels, with parameter count $|T|(L_U - 1)$, growing with
the domain. Approximate sets ($U = \BoolType$) and relations ($T$ a product) are
sub-cases.

\begin{center}
\begin{tabular}{lll}
\hline
Constructor & Lift & Channel form \\
\hline
$T \times U$ & $\Bernoulli{T} \otimes \Bernoulli{U}$ & Kronecker product \\
$L T$ & $\Bernoulli{T}^{\otimes n}$ (mixture if length noisy) & Kronecker power \\
$T \to U$ & $T \to \Bernoulli{U}$ & per-input Kronecker \\
$T + U$ & does \emph{not} factor (tag coupling) & not block-diagonal unless $\delta = 0$ \\
\hline
\end{tabular}
\end{center}

The first three rows are forced by Axioms~1 and~2 at the type-structural level;
the fourth records where those axioms' independence fails. \Cref{sec:composition-functor}
packages the three clean rules.

\subsection*{Worked example}

A 3-class classifier reporting a class label and a times-seen count has output
type $\{\text{cat}, \text{dog}, \text{bird}\} \times \mathbb{N}$, a product of a
3-element enumeration (governed by a $3 \times 3$ confusion matrix
$Q_{\text{class}}$) and a count (a CountMin-style $\Bernoulli{\mathbb{N}}$,
$Q_{\text{count}}$). Under independence the joint factors as
$\Bernoulli{\{\text{cat}, \text{dog}, \text{bird}\}} \otimes
\Bernoulli{\mathbb{N}}$, the Kronecker product $Q_{\text{class}} \otimes
Q_{\text{count}}$, with additive parameter count $3 \cdot 2 + K_{\mathbb{N}}
(L_{\mathbb{N}} - 1)$. To compose two such classifiers one applies the
chapter-12 join rate to the label and the chapter-10 sketch composition to the
count, with no cross-interaction: the type structure says where each rule goes.
Composing approximate structures, which used to need a per-structure derivation,
reduces to applying the product, list, and function rules to the components, with
the sum flagged as the place a tag error couples them.
