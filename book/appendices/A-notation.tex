\chapter{Notation and Conventions}
\label{app:notation}

This appendix collects the notation used across the chapters. Symbols that
appear in a single chapter are defined where they are used and are not repeated
here.

\section*{Conventions}

\begin{itemize}
  \item \emph{Truth values.} $\top$ and $\bot$ denote true and false. A
    \emph{latent} (true) value is the value an exact computation would return;
    an \emph{observed} (reported) value is what the approximate structure
    returns. Observed quantities carry a tilde or a hat when both appear in one
    expression ($b$ latent, $\tilde{b}$ observed).
  \item \emph{Rates are conditional.} Every error rate is a probability
    conditional on the latent value, never on the report:
    $\fprate = \Prob{\tilde{b} = \top}[b = \bot]$ and
    $\fnrate = \Prob{\tilde{b} = \bot}[b = \top]$. Quantities conditional
    on the report (PPV, NPV) depend on the prevalence and are treated separately
    (\Cref{ch:classification-measures}).
  \item \emph{Channel matrices are row-stochastic.}\index{channel matrix} Rows are indexed by the
    latent input and columns by the reported output, both in the order
    $(\top, \bot)$, so $Q_{xy} = \Prob{\text{report } y}[\text{latent } x]$
    and each row sums to one. Applying $Q_1$ and then $Q_2$ gives $Q_1 Q_2$.
  \item \emph{Independence.} Unless a statement says otherwise, distinct
    queries have independent error events (Axiom~1, \Cref{ax:element-indep})
    and rates are stable over repeated use (Axiom~2,
    \Cref{ax:block-rates-indep}). Part~V studies what happens when these fail.
  \item \emph{Logarithms} are base two unless written $\ln$. The constant
    $\log_2 e \approx 1.4427$ recurs as the space overhead of an optimally
    tuned Bloom filter over the lower bound.
  \item \emph{Model order versus composition depth.} \emph{Model order} is the
    number of blocks in the coarsest partition of the input domain on which the
    error rate is constant\index{model order} (\Cref{def:model-order}). It is distinct from
    \emph{$k$-fold composition}\index{k-fold composition@$k$-fold composition}, the number of times an approximate operation
    is applied in series.
\end{itemize}
